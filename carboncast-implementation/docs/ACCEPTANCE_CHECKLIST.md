# Acceptance Checklist

## Attribution
- [ ] Canonical upstream URL verified from repository evidence.
- [ ] Original license preserved.
- [ ] README credit added.
- [ ] Notice/credits credit added.
- [ ] No claim of upstream endorsement.

## Removal
- [ ] Original promotional social handles/IDs removed.
- [ ] Original social buttons and profile links removed.
- [ ] Donation/funding/tip/sponsor UI removed.
- [ ] Donation-only backend/API/IPC/deep-link code removed.
- [ ] Donation environment keys, flags, analytics and tests removed.
- [ ] No blank navigation slots, separators or dead routes remain.
- [ ] Operational IDs and normal billing remain intact.

## Branding
- [ ] Product name updated consistently.
- [ ] UI logo installed.
- [ ] Desktop/package icons installed.
- [ ] Favicons and PWA icons installed.
- [ ] Splash screen installed.
- [ ] Theme colors/tokens integrated into native theme system.
- [ ] Carbon texture remains restrained.
- [ ] Keyboard focus and contrast remain accessible.

## Verification
- [ ] Formatter passes.
- [ ] Type checker passes.
- [ ] Linter passes.
- [ ] Tests pass.
- [ ] Production build passes.
- [ ] Package/installer launches correctly.
- [ ] Promotion audit reviewed with remaining matches justified.
