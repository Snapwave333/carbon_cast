# Upstream Attribution Policy

CarbonCast IPTV is a fork. Branding cleanup must not erase provenance.

## Required credit

- Preserve the original license verbatim.
- Preserve copyright notices and source headers.
- Link to the verified canonical upstream repository in README and notices.
- Identify CarbonCast IPTV as an independent fork.
- State that upstream maintainers do not endorse the fork.

## Not acceptable as credit

- Keeping an original maintainer's social profile in the app.
- Keeping a donation button.
- Linking to a personal payment page.
- Replacing the repository URL with a vague “based on open source” sentence.

## Resolution order

1. `upstream` remote fetch URL.
2. Package manifest repository/homepage fields corroborated by license/README.
3. Explicit “forked from” link in README/docs.
4. Earliest repository history and copyright headers.
5. `origin` only when it is clearly the canonical source rather than the user's fork.

When evidence conflicts, stop attribution edits and report the candidates. Do not guess.
