# Agent Rules for CarbonCast Branding Work

## Scope
Only rebrand the application, preserve upstream attribution, and remove inherited promotional social identity plus donation functionality/UI.

## Safety boundaries
- Preserve licenses, notices, copyright, commit history and attribution.
- Never rewrite git history to hide the fork origin.
- Never delete operational IDs based solely on a keyword match.
- Never delete paid product billing unless it is conclusively donation-only.
- Never leave disabled donation/social placeholders.
- Never claim upstream endorsement.

## Quality bar
- No mock assets in production paths.
- No broken imports, routes, menu separators, translation keys or tests.
- No unverified upstream URL.
- No hand-waved build result.
- Use the repository's existing architecture and conventions.
