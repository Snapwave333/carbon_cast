The carbon-fiber weave behind the app is gone. App surfaces now sit on a slowly
drifting aurora gradient — magenta into blue, cyan and red — under a thin layer
of frosted glass that keeps text easy to read. The gradient is anchored to the
window, so it reads as one continuous backdrop instead of repeating per panel,
and it holds still if you have reduced motion turned on.
