The TV guide grid got a visual polish: alternating row shading, softer hour
lines, a calmer airing-now treatment, channel logos on defined plates, and
genre-tinted episode chips. The time badge no longer overlaps hour labels,
sliver-thin cells hide clipped text fragments, and channels without
programme data for the day now say so instead of showing an empty band.
