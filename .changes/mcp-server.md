IPTVnator now ships an MCP server, so AI assistants can browse your library —
playlists, channels, de-duplicated categories, name search, favorites,
downloads, and live EPG ("what's on now" / now-next for a channel) — by reading
the local database. Point any MCP client at `apps/mcp-server/src/main.mjs`.
